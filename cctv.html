TV PROGRAM / CONTENT EXECUTION

《中国美食大会第二季》

这是最能体现我“内容策划 + 现场执行”能力的一段经历。参与四川篇5期、贵阳篇5期内容制作，在复杂节目结构中完成选手调度、流程衔接和现场节奏配合。

项目角色

节目制作实习生 / 节目编导 / 内容执行

在大型节目制作体系中，我不只是完成单点任务，而是需要持续理解节目流程、选手状态、内容节点和现场节奏之间的关系。

前期策划

把地方美食转成可执行的节目内容

参与贵阳篇前期菜品设计、竞赛单元、投票机制、选手筛选及场地勘察。工作重点不是“想一个点子”，而是判断这个点子是否符合节目定位、是否能形成互动、是否能在现场真正执行。

现场执行

多选手、多环节并行下的节奏控制

围绕每篇24位选手、3组竞赛单元、4位嘉宾与100位大众评审的结构，参与选手调度、流程衔接，并根据备菜、烹饪和出品进度动态调整现场推进。

能力沉淀

我学到的是内容与执行不能分开

一个节目环节再有创意，如果现场无法顺畅执行，就不能成为真正有效的内容。这段经历让我更适合内容策划、节目编导、活动内容执行等岗位。
